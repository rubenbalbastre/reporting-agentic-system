# Documentation Guide

This folder is split into product docs and technical docs.

## Start Here

If you want to understand the product first:

- [Reports](reports.md): main UX and product flow for report creation, chat iteration, preview, and export
- [Skills](skills.md): main UX and product flow for draft teaching, publish, and library browsing

If you want to understand the implementation:

- [API Reference](api.md): concise HTTP endpoint reference
- [Database And Storage](database.md): PostgreSQL schema and shared volume layout
- [Agents Architecture](agents.md): agent roles, workspaces, and design tradeoffs
- [Container Architecture](container-architecture.md): Docker services, volumes, and runtime topology

## Suggested Reading Order

For recruiters or product-focused readers:

1. [Reports](reports.md)
2. [Skills](skills.md)
3. [README](../README.md)

For engineers evaluating the system design:

1. [Reports](reports.md)
2. [Skills](skills.md)
3. [Database And Storage](database.md)
4. [Agents Architecture](agents.md)
5. [API Reference](api.md)
